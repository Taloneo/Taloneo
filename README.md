# Leonardo Potenza / Taloneo

I build, automate and test systems where software meets the physical world.

Creative technologist, sound artist and connected-systems builder working across physical avalanche entropy ([Analog Seed](https://analogseed.dev/)), generative web architecture ([SoulMirror](https://soulmirror.work/)), embedded hardware, networked installations, sound/MIDI/OSC routing and physical fabrication.

Portfolio: https://leonardopotenza.com

## Selected systems & works

### [Analog Seed](https://analogseed.dev/) & [Creative Studio](https://app.analogseed.dev/)
Conditioned physical entropy from proprietary solid-state avalanche noise sources, continuous SP 800-90B online health gates, `HMAC-SHA-256` conditioning (`CP2` credit of 2 bit/sample), zero-bias primitives (`POST /v1/draw`), Ed25519 signed entropy receipts (`AS-RECEIPT-V1`), an MCP server for AI agents, and a standalone Creative Studio webapp for numbers, color palettes, WebAudio/MIDI chords and verifiable giveaways.
- Portal & API Docs: https://analogseed.dev/
- Creative Studio: https://app.analogseed.dev/
- Case study: https://leonardopotenza.com/en/cases/patagonia-entropy-node/

### [SoulMirror](https://soulmirror.work/)
Generative multilingual web artwork built from live advertising inventory, local browser profiling signals and an infinite Mondrian visual field on Cloudflare Pages/Functions.
- Case study: https://leonardopotenza.com/en/cases/soulmirror/

### [Quorum Sensing](https://github.com/Taloneo/Quorum-Sensing)
Collaborative gastrosonic system connecting three diners through motion-sensing tableware (MPU-6050, ESP8266, Wi-Fi/MQTT, Processing, MIDI) and bodily vibration. I contributed to the research, design, prototyping, construction and programming.
- Peer-reviewed article (co-author), *Revista Vórtex* 11(1), 2023: https://doi.org/10.33871/23179937.2023.11.1.7774
- Conference paper (co-author), *ubimus2022*: https://doi.org/10.5281/zenodo.6836026
- Case study: https://leonardopotenza.com/en/cases/quorum-sensing/

### Smell Organ (*Perfume de yuyo y alfalfa*)
Networked crossmodal instrument mapping live piano input to spatialized aroma and light across Wi-Fi microcontroller towers (MIDI/OSC). Shared realization with Sebastián Tedesco, Camilo Álvarez and Carlos Sztaynberg (authors: Tedesco and Mesz); I developed the instrument and operated it on site, including at BienalSur 2019.
- Case study: https://leonardopotenza.com/en/cases/smell-organ/
